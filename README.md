# Teddy Martins Portfolio Website

A responsive, single-page portfolio designed to present web development, UI/UX, Figma, and visual art work in a professional format.

## Files
- `index.html` — page content and project links
- `styles.css` — responsive visual styling
- `script.js` — mobile navigation behavior
- `portfolio-mockup.png` — visual concept preview

## Preview locally
Open `index.html` in a modern browser. Google Fonts are loaded online; the page still works if they are unavailable, using fallback fonts.

## Publish to GitHub Pages
1. Download and unzip the project.
2. Review `index.html` and confirm the project links are correct.
3. Upload `index.html`, `styles.css`, and `script.js` into the root of your portfolio repository, replacing the old files if you want this page to become the main page.
4. Keep the existing `Art/` folder if you want to preserve your original artwork gallery. This new landing page links to the existing `art.html` gallery.
5. Commit the changes and wait for GitHub Pages to publish.
6. Check the live site on desktop and mobile.

## Before using on a resume
- Verify that every Figma file is publicly viewable by people who are not signed in.
- Add a professional email or LinkedIn URL to the contact area if you want recruiters to reach you directly.
- If you have a PDF resume hosted online, add its URL as a dedicated Resume button.
- Keep project descriptions aligned with the features and technologies you personally implemented.

## Personal headshot
`teddy-headshot.jpg` is the profile photo used in the site header and footer. Replace it with another image using the same filename if you update your headshot later.
